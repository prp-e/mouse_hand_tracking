# Mouse Hand Tracker

## Prerequisites 

1. Python 3.11 or 3.12 (or a version where mediapipe has installation candidate for `0.10.21`)
2. Windows or Linux (`autopy` is not compatible with macOS or it needs modifications I haven't done on my Macbook.)

## How to run?

The best way to run this program is just this:

```
pip install mediapipe==0.10.21 autopy
python main.py
```

## Disclaimer

This was just a _proof of concept_ project and needs to be updated wit newer versions of _mediapipe_ library.
